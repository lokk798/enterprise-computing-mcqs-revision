### Question 1

In a microservices architecture, what is the PRIMARY security challenge that the "Principle of Least Privilege" addresses when compared to monolithic applications?

- A) Increased network latency between services
- B) Managing multiple distinct databases and remote APIs requiring separate credentials
- C) Difficulty in implementing load balancing across services
- D) Complexity in service discovery and registration
- E) Challenges in maintaining consistent logging across services

**Correct Answer: B**  
_Explanation: With microservices, there are many more credentials to manage (distinct databases, remote APIs, etc.), making it crucial to grant minimal access levels to limit damage if credentials are compromised._

### Question 2

Which of the following statements about JWT tokens in microservices security is MOST accurate?

- A) JWT tokens should always be stored in localStorage for persistence across browser sessions
- B) JWT tokens eliminate the need for any server-side session management
- C) JWT tokens allow decentralized authorization decisions while maintaining authentication data integrity through signing
- D) JWT tokens are automatically encrypted and cannot be decoded without the private key
- E) JWT tokens should never have expiration dates to avoid user inconvenience

**Correct Answer: C**  
_Explanation: JWT tokens enable decentralized authorization by allowing microservices to make authorization decisions locally while maintaining data integrity through signing. They can be read without decryption but cannot be tampered with due to the signature._

### Question 3

In the context of "Defense in Depth" for microservices, what makes this principle particularly effective compared to traditional monolithic security approaches?

- A) Microservices use stronger encryption algorithms than monoliths
- B) Each microservice has limited responsibility, reducing the attack surface per service
- C) Microservices automatically implement OAuth2 by default
- D) Load balancers provide better DDoS protection for microservices
- E) Container orchestration platforms have built-in security features

**Correct Answer: B**  
_Explanation: Defense in depth is strengthened in MSA because each microservice has limited responsibility, meaning if one service is compromised, the attacker's access is limited to that service's specific functionality and data._

### Question 4

What is the MAIN security risk associated with choosing simplicity in credential management by "granting broader privileges to fewer credentials" in a microservices environment?

- A) Increased computational overhead for authentication
- B) Difficulty in tracking user sessions across services
- C) If credentials are compromised, the attacker gains access to multiple services and resources
- D) Problems with service-to-service communication timing
- E) Incompatibility with modern identity providers

### Question 5

Which Spring Security annotation configuration is REQUIRED to enable method-level security with both Spring annotations and JSR-250 standard annotations?

- A) `@EnableGlobalMethodSecurity(prePostEnabled = true)`
- B) `@EnableGlobalMethodSecurity(securedEnabled = true)`
- C) `@EnableGlobalMethodSecurity(jsr250Enabled = true)`
- D) `@EnableGlobalMethodSecurity(securedEnabled = true, jsr250Enabled = true)`
- E) `@EnableGlobalMethodSecurity(prePostEnabled = true, securedEnabled = true, jsr250Enabled = true)`

**Correct Answer: D**  
_Explanation: To enable both Spring's @Secured annotations and JSR-250 standard Java annotations, you need both securedEnabled = true and jsr250Enabled = true. PrePostEnabled is for @PreAuthorize/@PostAuthorize._

### Question 11

- D) CSRF protection requires manual implementation of token storage in databases

### Question 16

In the context of JWT implementation for microservices, what is the MAIN trade-off between centralized and decentralized authorization approaches?

- A) Centralized authorization provides better performance but worse security
- B) Decentralized authorization eliminates the need for authentication
- C) Centralized authorization is simpler to implement but requires gateway changes for new service permissions; decentralized allows services to make their own decisions using JWT claims

### Question 20

Which of the following statements about microservices security patching and maintenance are MOST critical for enterprise security? (Multiple correct answers)

- A) Container scanning tools like Aqua should be integrated into CI pipelines
- B) Backups should be stored in the same environment as the application for quick access
- C) Regular automated rebuilds of microservices help prevent persistent malicious code
